Desktop Server — Hardware Specifications

The ComplyTrack server runs on a small desktop PC or mini PC placed at the customer's office. The stack is lightweight (Node.js + MongoDB + React), so consumer-grade hardware is sufficient.

ComponentMinimum SpecRecommended SpecNotes
CPU Intel i3 / AMD Ryzen 3 (4 cores) Intel i5 / AMD Ryzen 5 (4–6 cores) Node.js is single-threaded; MongoDB benefits from faster cores, not many cores
RAM 8 GB DDR4 16 GB DDR4 MongoDB uses ~2–4GB, Node.js ~500MB, OS ~2GB. 8GB is fine for <10 stores
Storage 256 GB SSD 512 GB SSD MongoDB data + PDFs + uploads. SSD is mandatory — HDD will be painfully slow
Network 100 Mbps Ethernet 1 Gbps Ethernet Internal LAN only — no internet bandwidth needed for the app itself
OS Windows 10 / Ubuntu 22.04 Windows 11 / Ubuntu 24.04 Docker runs natively on both; Windows is simpler for non-technical users
Display Any monitor (for initial setup) 22" monitor (optional) Headless operation after setup — access via browser from any PC on LAN
UPS — 600VA UPS Prevents data corruption during power cuts; recommended for India

Why This Hardware Is Enough

ConcernReality
"MongoDB needs a powerful server"No. For 5–15 stores, the database is <1GB. MongoDB handles millions of documents on a laptop.
"We need a server room"No. A mini PC sits on a desk. It's the size of a paperback book.
"What about backups?"MongoDB dumps to a USB drive weekly. Automated via cron job.
"What if it crashes?"Docker auto-restarts the container. The mini PC reboots and the app comes back up.
"Internet goes down?"App runs on LAN — no internet needed. Internet only needed for email alerts.

Pitch Value Proposition

Don't sell software. Sell compliance peace of mind.

A business owner who gets fined ₹50,000 for missing a filing will gladly pay ₹85,000 to never let that happen again. The pitch isn't "buy this app" — it's "never get fined, never miss a deadline, never lose sleep."
